# minifoolio 
A modern modern, minimal portfolio starter kit for developers and creatives. Built with nextjs, shadcn/ui, tailwindcss, gsap and react-bits.

## <a name="quickstart">⚡ Quick Start</a>
1. Clone this repository
```
git clone git@github.com:byfonz/minifolio.git
```
2. Open cloned repository
```
cd minifolio
```
3. Install dependencies:
```bash
pnpm install
# or
npm install
```
4. Run locally:
```bash
pnpm run dev
# or
npm run dev
```
5. Open [http://localhost:3000](http://localhost:3000) with your browser to see the site.

6. You can start editing the page by modifying `data/index.ts`. The page auto-updates as you edit the file.
